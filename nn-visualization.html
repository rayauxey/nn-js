How the network reads a handwritten digit

A fully connected network turns 784 pixel brightnesses into 10 probabilities. Each layer multiplies the previous layer by a weight matrix, adds a bias, and applies an activation. Below, real test image #0 (a 7) flows through the trained model. It predicts 7 with 100.00% confidence.

One forward pass

Every layer is a matrix multiply plus a simple non-linearity

Hidden layers use ReLU (max(0, z)), so a neuron either stays silent or passes its signal on. For any given digit, only part of the network lights up. The output layer uses softmax to turn 10 scores into probabilities that sum to 1.

How it learned the weights

During training, 20% of hidden neurons are randomly switched off on each step (dropout). This stops the network from relying on any single neuron.

Inside hidden layer 1

What the first layer learned to look for

Each neuron in hidden layer 1 has 784 weights, one per pixel, so its weights can be drawn as a 28×28 image. Blue pixels push the neuron to fire when ink is there. Red pixels hold it back. Together they act as stroke and edge detectors. These are the 60 neurons with the largest weights.

Each map is scaled to its own largest |weight|.3 / 5

Results on 10,000 unseen test images

Predictions, and where it gets confused

The network never saw these images during training. It gets 9,817 of 10,000 right (98.17%). Most mistakes are on digits that are genuinely ambiguous or badly written.
